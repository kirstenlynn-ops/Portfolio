Project 2 | Clinical Data Remediation 🏥🧹

About

An automated Python pipeline for clinical data remediation and multi-dimensional quality assessment of the UCI Diabetes 130-US Hospitals dataset, targeting a 25% improvement in the Data Quality Index (DQI) through MICE/KNN imputation.

Project Workflow 🪜

  1. P2 - S1 Data Profiling: Baseline assessment of dataset, null detection, and initial DQI calculation.
  2. P2 - S2 Data Remediation: Apply MICE/KNN imputation and Regex-based ICD-9 normalization for completeness and consistency.
  3. P2 - S3 Visualization: Generate Comparative Distribution Plots and KDE charts to communicate improvements.
  4. P2 - S4 Reporting: Export findings and pipeline summary for stakeholders and GitHub Pages deployment.

Deliverables 📂

  • Automated Python remediation pipeline (DataRemediator class)
  • Comparative distribution visualizations (Matplotlib & Seaborn)
  • DQI improvement report and annotated bibliography
