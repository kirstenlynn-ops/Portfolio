Project Overview 📄

This project transforms raw Spotify streaming history into a behavioral engagement dashboard. By comparing two users’ listening volume, temporal habits, diversity of artists and albums, and skip/shuffle behavior, the dashboard highlights patterns of exploration versus repetition.

In real-world applications, this type of analysis supports personalized recommendation systems, user segmentation, and product engagement strategy for streaming platforms.

Project Workflow 🪜

  • P4 - S1 Data Wrangling: Cleaning timestamps, merging histories, feature engineering
  • P4 - S2 Behavioral Metrics: Engagement, repetition, discovery, skip/shuffle rates
  • P4 - S3 Dashboard Development: Plotly visualizations + static HTML export
  • P4 - S4 Insight Storytelling: Translating patterns into user behavior narratives

Key Results 🟰

  • Engagement Differences: User A listens more consistently across time
  • Exploration vs Habit: User B demonstrates broader artist and album diversity
  • Listening Style: Skip/shuffle patterns show distinct consumption preferences
  • Behavioral Shifts: Discovery trends alternate yearly, with User B peaking in the final year

Technical Stack 🔨

  • Data Processing: pandas, NumPy
  • Visualization: Plotly Express, Plotly Graph Objects
  • Dashboard Export: Static HTML Reporting
  • Environment: Jupyter Notebook + GitHub Pages Deployment

Ethical Considerations ⚖️

  • Listening data anonymized (no personal identifiers)
  • Behavioral analytics used only for insight, not surveillance
  • Some tracks are labeled as explicit and may reference adult themes such as violence, substance use, or mature subject matter.
  • Dashboards designed for transparency and interpretability
  • Future recommendation use would require consent and opt-out controls
